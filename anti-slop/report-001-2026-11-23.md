# Anti-Slop Remediation Report #001

- **Proyek:** DTMF STFT Denoiser (Kelompok G - Pemrosesan Sinyal Digital)
- **Tanggal:** 2026-11-23
- **File Dimodifikasi:** `templates/index.html`, `static/app.js`
- **Status Eksekusi:** Seluruh temuan #1 sampai #12 telah diperbaiki dan diverifikasi.

---

## Rincian Perbaikan Temuan

1. **[R-02] Copywriting (Em Dash)**: **FIXED**
   - Mengeliminasi seluruh karakter em dash (`—`) dari `index.html` dan `app.js`. Diganti dengan tanda titik dua (`:`), rentang teks terstruktur, atau fallback eksplisit (`0.0 dB`, `0.0 ms`, `MENUNGGU DATA`).

2. **[R-25] Color Contrast**: **FIXED**
   - Seluruh teks sekunder dan label skala ditingkatkan dari `text-slate-400` / `text-slate-500` menjadi kontras tinggi (`text-slate-300`, `text-slate-200`, `text-cyan-400`, `text-amber-300`).
   - Lolos uji contrast scanner (WCAG AA rasio > 4.5:1).

3. **[R-32] Keyboard Accessibility & Focus Indicator**: **FIXED**
   - Menambahkan rule `:focus-visible` global (`outline: 2px solid #06b6d4; outline-offset: 2px`) untuk semua tombol keypad, input angka, select, range slider, dan tombol form.

4. **[R-39] Accessible Semantics & Interaction Affordances**: **FIXED**
   - Menetapkan `cursor: pointer` universal untuk semua tombol, checkbox, slider, dan label.
   - Menambahkan `aria-label` deskriptif pada 16 tombol DTMF (misal: "Tombol 1, nada 697 Hz dan 1209 Hz").
   - Menambahkan atribut `aria-expanded` dan `aria-controls` pada tombol toggle numpad.
   - Menambahkan media query `prefers-reduced-motion` untuk menghentikan animasi non-esensial.

5. **[R-08] Button Arrows**: **FIXED**
   - Menghapus panah dekoratif `&rarr;` dari header simulator dan tombol "Kirim dan Uji Denoising".

6. **[R-19] Animations & Motion Libraries Integration**: **FIXED**
   - Mengintegrasikan **Lenis** (`lenis.dev`) untuk smooth scrolling vertikal berbasis RAF.
   - Mengintegrasikan **GSAP** (`gsap.com`) untuk stagger entrance workstation panel dan transisi toggle numpad.
   - Mengintegrasikan **Motion** (`motion.dev`) untuk micro-interaction taktil (scale press physics) pada 16 tombol keypad DTMF dan tombol aksi.

7. **[R-10 & R-12] Shadow & Depth**: **FIXED**
   - Menghapus drop-shadow mengambang generic. Menggantinya dengan border 1px presisi instrumen (`border-telecom-border`), elevasi panel bertingkat (`#0e1520` ke `#141e2c`), dan display terminal sunken (`#05080c`).

8. **[R-01] Color & Gradients**: **FIXED**
   - Mengganti palet default Tailwind Indigo dengan tema teknis instrumen telekomunikasi: Dark Obsidian (`#070b10`), Cyan (`#06b6d4`) untuk frekuensi tinggi & aksen utama, Amber (`#f59e0b`) untuk frekuensi rendah DTMF, dan Emerald (`#10b981`) untuk status decoding & FFT sinyal bersih.

9. **[R-05] Layout & Page Structure Rhythm**: **FIXED**
   - Mengorganisasi antarmuka menjadi 4 workstation logis: Simulator Generator Sinyal, Ruang Kontrol Parameter STFT, Deck Observasi DTMF & Skenario P4, dan Dual-Domain Visualizer.

10. **[R-06] Typography & Character**: **FIXED**
    - Mengintegrasikan font Google: **Space Grotesk** untuk heading UI teknis dan **JetBrains Mono** untuk seluruh metrik, frekuensi Hz, dB, timer, dan tabel data.

11. **[R-11] Border Radius**: **FIXED**
    - Mengubah border-radius playful (`rounded-2xl`, `rounded-xl`) menjadi sudut presisi laboratorium (4px sampai 8px).

12. **[R-21] Technical Lab Dark Theme**: **FIXED**
    - Antarmuka mengadopsi tema instrumen laboratorium gelap dengan konfigurasi Plotly.js kustom (background transparan/gelap, gridline `#1a2533`, teks sumbu `#94a3b8`, trace berpenanda frekuensi DTMF).
